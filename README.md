## 🎮 MSFS Cockpit Solutions

Design and development of advanced cockpit solutions for Microsoft Flight Simulator.

My work involves investigating aircraft implementations to identify undocumented variables, events and interfaces required for reliable hardware integration.

This includes:

- identifying undocumented Event IDs, LVars and BVars through systematic analysis and testing
- analysing aircraft systems and cockpit logic
- designing efficient hardware workflows
- developing Stream Deck profiles with PilotsDeck
- developing SPAD.neXt profiles for:
  - Logitech/Saitek Flight Multi Panel
  - Logitech/Saitek Flight Radio Panel
  - Logitech/Saitek Flight Instrument Panel
  - Logitech/Saitek X52 Pro HOTAS

The resulting profiles provide fast and intuitive access to aircraft systems, reducing cockpit workload throughout every phase of flight.

Aircraft I have investigated and developed profiles for:

- iniBuilds Airbus A330
- Boeing 737 MAX
- Cessna 208B Grand Caravan
